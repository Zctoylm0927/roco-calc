# 2026-11-21 工作总结

## 用户需求

参考 `instruction-20261121.md`，实现洛克王国世界对战伤害计算器的后端：

1. 根据精灵的六项种族值、性格、天分，算出战斗中的实际面板值。
2. 根据双方实际面板，计算精灵 A 用技能 B 打精灵 C 的伤害，考虑技能威力、物攻/魔攻、物防/魔防、属性克制等。
3. 先做后端并核对数据，之后再考虑前端。

用户指定的参考：biligame wiki 和 rocopvp.tzrain.wiki 的战斗计算器。

## 公式从哪里来

- 面板公式：读 tzrain 计算器的公开前端代码，确认了等级 60 的换算、性格 1.2/0.9、天分每点 +3 种族值、以及取整顺序。
- 伤害公式：同样从 tzrain 的公开代码确认，包括本系 ×1.25、等级系数 `(45×等级/100+10)/41`、显示威力先取整、单次伤害最后向下取整。
- 属性克制：wiki 的 `Module:Pets/data/Types`；和 tzrain 内置 18×18 表逐条比对，1023 条全部一致。
- 公开文章里的实例：岚鸟（物攻 128、天分 10）用扇风打奇丽花（物防 121、天分 10），显示威力 356、伤害 332。

## 关键结论

1. 60 级面板：
   - 非生命：`round((round(1.1 × (种族 + 3×天分)) + 10) × 性格) + 50`
   - 生命：`round((round(1.7 × (种族 + 3×天分)) + 60 + 10) × 性格) + 100`
2. 取整细节：天分为 0 且数值恰好 .5 时用「半到奇数」，其余用普通四舍五入（向正无穷方向）。
3. 本系加成是 ×1.25，不是宝可梦的 ×1.5。
4. 双克制是 ×3，不是 ×4；双抵抗是 ×0.25；一克一抗是 ×1。
5. PVP 伤害没有暴击和随机浮动。
6. 三个社区计算器的面板取整时机不完全一样，性格不是「不加不减」时约 18% 的数值会差 1 点。本项目决定以用户指定的 tzrain 为准。
7. 洛克的性格语义和宝可梦不完全一样，例如「大胆」是物攻↑/物防↓。性格数据已和 wiki 的养成参考模块逐条核对，30 条全部一致。

## 当前限制

- 不含特性、道具、天气、场地、印记。
- 不含暴击和随机浮动。
- 不校验精灵是否能学目标技能。
- 不计算速度先后、先手、换人。
- 不含成长星级/PVE 数值，默认 60 级 PVP。
- 特殊威力规则需要手动指定威力。
- 状态/防御/特性类技能不能套伤害公式，会直接报错。
- 取整以 tzrain 为准，和其他计算器可能有 ±1 差异。
