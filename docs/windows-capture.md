# RocoCapture：Windows持续截图工具

运行打包后的 `RocoCapture.exe`，不需要安装Python、Conda、OCR模型或独显。本版只持续抓取窗口并保存原始PNG，不识别游戏内容、不上传图片。

## 使用

1. 打开游戏并保持窗口正常显示，运行 `RocoCapture.exe`。
2. 在列表中选“洛克王国：世界”。尺寸应对应游戏内容，例如1920×1080，不包含标题栏；找不到时点“刷新窗口”。
3. 选择图片保存目录。默认在用户目录下的 `Pictures/RocoCaptures`。
4. 设置时长，默认 **10分钟**，可覆盖这段约8分38秒的参考对局。默认目标 **20 FPS抓屏、每1秒保存一张PNG**；这两个频率分别设置。
5. 点“开始监控”或按 **F9**。工具自动最小化，切到游戏正常对战；再次按F9可提前停止。
6. 需要额外留一张当前画面时按 **F8**。停止后也可按F8单独截图。
7. 点击任务栏恢复工具，点“打开图片目录”。请把几张操作帧、攻击帧的原始PNG以及 `session.json` 传回来测试。

游戏切到后台或最小化时暂停抓图，切回后继续；10分钟仍按实际经过时间计时。窗口可以移动，程序每次重新取内容区域；移出屏幕或关闭窗口会停止并保留已存图片。截图不缩放、不拼接、不经过聊天软件压缩。

**保存间隔0**表示尝试保存每一帧，适合需要检查伤害浮字的完整片段。文件数量取决于频率、时长和实际保存速度。保存队列固定最多3帧；PNG写盘跟不上时会跳过并计数，不能把目标FPS当作实际保存FPS。默认1秒一张是长时间采样模式，不足以覆盖每个短暂浮字。

## 输出

每次监控创建独立文件夹：

```text
session_日期时间_编号/
  frame_0000001_000000.123s.png
  frame_0000021_000001.145s.png
  frames.jsonl
  session.json
```

文件名中的序号是抓屏序号，默认1秒保存一张时序号不连续是正常的。`frames.jsonl` 记录每张图片的实际时间、游戏内容区域、原始尺寸及DPI；`session.json` 记录实际抓到/保存/保存队列跳过的数量及抓屏耗时。尚未结束时以已保存PNG和逐帧日志为准。

使用MSS截取屏幕区域，所以游戏需保持前台可见；程序不会强制让后台游戏持续渲染。F8/F9被其他程序占用时，界面会提示，仍可使用窗口按钮。

## 构建与验证

仓库的 `Build Windows MSS capture tool` Actions任务在Windows x64上安装独立截图依赖并用PyInstaller构建单文件exe。成功后在任务的Artifacts中下载 `RocoCapture-windows-x64`，解压得到exe、本文和SHA256。原片、截图和OCR环境不参与构建。

开发机有Windows Python 3.11时，也可运行：

```powershell
./build_capture.ps1
```

输出为 `dist/capture/RocoCapture.exe`。构建任务会运行打包后的 `--self-test`：创建实际640×360原生窗口，验证MSS保存PNG的尺寸和中心像素，并执行短时持续抓屏。该验证不替代在你的核显机器上测量1920×1080持续10分钟的真实表现。
